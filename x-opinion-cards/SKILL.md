# X 观点图文

分批建立有来源、可续跑的 X 观点库，并将能独立读懂的观点制作成中文图文。默认图片只展示观点，不展示人物、作者、头像、粉丝量、头衔、平台界面或其他署名。来源保存在本地记录及发布配文中。

## 运行模式

- **观点库采集模式**：从指定博主的历史帖子分批读取、筛选、去重，先列出指定数量的观点，不制图。执行时必须提供“目标观点数”，例如 20 条；没有提供时先询问这一项，再开始采集。详细规则见 [references/collection-mode.md](references/collection-mode.md)。
- **图文生成模式**：从现有观点库、指定候选编号或给定帖子，生成一个或多个观点的纯文字图片和发布配文。
- 一次任务可以先采集再制图，但只有用户明确要求“直接生成”或指定要生成的编号时才进入制图。

## 输入与执行方式

- 接受单条帖子、线程、博主主页、主题、指定候选编号，以及用户提供的原文或截图。
- 内置四位博主见 [references/creators.md](references/creators.md)。指定博主时只从指定范围筛选；未指定时从这四位中选与主题最贴近的内容，无须平均分配。
- “采集 N 条观点”指最终列出的合格观点数量，不是扫描 N 条帖子。观点库采集模式必须给出 N；如用户只说“爬取一些/所有观点”，先询问目标观点数。可另外接受“最多扫描 M 条帖子”作为停止上限。
- “生成 N 个观点”指 N 个独立观点，每个观点可有一张或多张图片；“生成 N 张图”指图片总数。图文生成数量未指定时默认一个观点、一张图，内容过长时说明分页。
- 用户说“先筛选/让我选”：交付候选列表后等待选择。用户说“生成/直接做”：已授权选题和制图，直接完成；不额外插入确认步骤。
- 已选定文案只调整版式时，不重新搜集或替换观点。用户明确给出的文案、数量和风格优先于默认值。

## 获取与筛选

1. 读取对应原帖和必要上下文，保存帖子永久链接、作者、发布日期（可取得时）、访问日期与实际读取渠道。主页链接不能代替原帖链接。
2. 优先原帖；不可访问时可用作者官网同文、可追溯的线程镜像或用户提供内容，并记录渠道。搜索摘要只用于发现，不据此补写缺失段落。来源仍不充分时交付已核实部分，指出缺少的内容；不要假装读完主页或全量历史。
3. “最近”或日期范围必须核对帖子的实际发布日期。未指定时间时允许历史好内容，不宣称最新。采集模式按目标观点数分批读取，不声称覆盖账号全部历史。
4. 优先个人成长、行动、学习、习惯、注意力、人生选择，以及有具体含义的鼓励性观点。每个候选至少两句相互关联的完整句子；观点与理由、解释或方法能独立读懂。
5. 排除纯个人经历、推广、空洞口号、无上下文的隐喻、仅一句格言和同义重复。不能把作者经历改写成作者没有说过的普遍道理，也不能为了凑两句添加推论。
6. 引用他人的帖子要识别实际发言者，不能直接归给发帖博主。跨帖子综合时列出全部来源，并标为综合整理。

候选提供稳定编号、直白标题、完整中文观点、作者、原帖链接及“翻译/观点整理/综合整理”类型。保留被选编号，不因排序改变编号；同一作者已有收藏按原帖链接及语义去重，重做同一观点时创建版本。采集结果不自动进入制图。

## 文案与制图

- 中文自然、具体，保留原意和适用条件。标题应概括正文，不使用“知识喂养了我”一类读者无法直接理解的抽象表达。
- 图片正文保留完整观点。短内容可以不另设标题，避免标题和正文重复；长内容按完整意思分页，不能只给标题或为了页数扩写。
- 翻译与整理明确区分，不把整理内容加引号当作逐字原话，不以删除署名声称原创或取得授权。保存来源不等于获得转载许可；避免整篇搬运，遇到长篇内容优先简短概述和自己的分析，并区分两者。
- 按 [references/visual-style.md](references/visual-style.md) 制作。本环境默认使用可用的 imagegen skill / 内置图像工具，遵循其调用要求；需要参考样张时先查看 [assets/text-card-reference.png](assets/text-card-reference.png)。
- 生成工具不可用时，保留审核后的文案和排版说明，明确未生成图片，不把文本文件当作已完成图文。用户明确要求本地模板或程序排版时可使用 HTML/CSS 或 Pillow，并实测成图。
- 每张生成后打开检查：中文字准确、无遗漏/新增、无裁切、字号适合手机、段落完整、无人物或署名、比例正确。出现错字或溢出时修正后重新查看。

## 文件与交付

默认在当前项目 `outputs/x-opinion-cards/` 下按博主归档；用户指定输出目录时使用指定目录。每条内容目录示例：

```text
Dan-Koe/
  2026-09-26-X01-先开始再学习/
    内容与来源.md
    发布配文.md
    01.png
    02.png  （仅在需要分页时）
```

`内容与来源.md` 保存候选编号、作者与主页、原帖链接、原帖日期、访问日期、获取渠道、与该观点有关的必要原文摘录、中文处理类型、完整中文稿和逐页文案。不要保存未读取的假原文。`发布配文.md` 包含简短引入、完整观点或补充解释及来源链接；图片内不必重复来源。

观点库采集文件按 [references/collection-mode.md](references/collection-mode.md) 保存。图文目录已有结果时使用新版本目录，保留旧结果。批量生成写一份本次索引，列出各观点、作者、图数和文件路径；部分失败时列明完成与未完成项，不静默少交付。

采集完成时报告目标观点数、实际合格观点数、扫描帖子数、覆盖日期范围、停止原因和无法访问的范围。制图完成时展示图片预览和绝对路径链接，说明生成了几个观点、几张图。不自动发布、定时后台抓取、添加用量或费用统计。此 skill 是代理执行流程，不自带常驻爬虫或账号登录服务。
