# 纯文字观点卡

## 默认样式

- 3:4 竖图，参考尺寸 1080×1440；保存清晰 PNG 或高质量 JPEG。
- 米白底、近黑文字、一种低饱和橙色强调，纸纹极轻或无纸纹。
- 中文标题可用宋体风格，正文以清晰易读为先。左对齐，边距约 8%，段落间留白。
- 标题约正文的 1.4–1.7 倍；避免参考图里标题过大、正文成为陪衬。每页最多强调一处短语，不整段着色。
- 不加人物、作者、头像、背书、平台标识、水印、装饰性编号、额外口号。分页顺序由文件名表达。
- 参考图只提供视觉方向，不能沿用其文案覆盖当前观点。短正文无需固定大标题；长正文优先分页，不强制固定字数。

## 图像生成提示词骨架

把方括号替换成实际内容后调用，不把变量名输出到图里：

```text
制作一张 3:4 中文纯文字观点卡，平面成品，无场景样机。
米白底，近黑文字，极轻纸纹，单一低饱和橙色点缀。
手机端易读，左对齐，宽松边距和行距；标题适度放大，正文保持醒目。
标题（逐字）：[本页标题；没有标题则省略]
正文（逐字，保留段落）：[已确定的本页完整正文]
仅强调：[一个短语，或不强调]
禁止添加或改写文字。无人像、无作者、无头衔、无署名、无平台界面、无水印。
```

批量时保持字体风格、配色、边距一致；每张使用独立的已确定文案。如工具输出保存到项目外，将最终文件复制到本次观点目录再交付。

## 质检要点

逐字对照文案，检查标点与换行；在手机预览大小检查可读性。避免句末仅一个字孤立成行、标题顶边、正文挤到下沿、不同页字号忽大忽小。分页后的每页要有可读的意思，整组必须保留完整论述。
